## 3. 灵魂（语言与记忆）

- **11 层记忆**：事实 / 心里话 / 认识天数 / 共同经历 / 昨日情绪 / 日记 / 周记 / 话题 / 约定 / 夸奖 / 生日与纪念日
- **主动性**：主动开口（心情影响频率）、小请求、记忆回访、接话题追问、今天在想的事、久别后模型开场白
- **日常感**：每日心情（影响行为参数）、跨天日记、每周小记、跨整点时段台词、节日台词、习惯观察、日常仪式
- **声音**：系统 TTS（默认关）；分句朗读+停顿+语气起伏、朗读范围（全部/仅聊天）、深夜轻声、口型同步
- **LLM**：DSH 云模型为主，可切本地 OpenAI 兼容端点；prompt 注入全部记忆层但控制在 ~2k 字符

## 5. 已知差距（诚实清单，详见 docs/02-FIDELITY-GAPS.md）

1. 头发是贴图发片 + 程序化补充，非分缕建模 → 轮廓体积感弱于动画
2. 脸型靠顶点变形逼近，不是重拓扑 → 侧脸/低头仍有差距
3. 袖口白环需几何/精确 UV，贴图级已证明不可行
4. 屏幕空间线稿实验已否决（假边、糊）
5. 动画里手绘作画笔触无法在实时 PBR/赛璐璐管线里完全复刻
6. 模型为 TDA 个人使用素材，不可再分发

## 6. 需要用户参与的部分

- **试听声音**：设置 → 声音 → 「让她说话」开；可选声线/语速/音调/预设；若有 macOS 系统中文声线会自动选「婷婷」
- 若觉得太吵：朗读范围切「仅聊天回复」
- 想要看脸：取景切「半身」或「自动」
- 想让她更了解你：多聊，或直接说「我生日是 X 月 X 日」「等…我们一起…」
