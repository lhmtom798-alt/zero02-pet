# 02 的人格内核（Persona）

桌宠的「灵魂」在 `src/client/persona.js`，不依赖任何外部服务，全部由本地提示词 + 宿主代理驱动。

## 组成

1. **身份锚点**：02（Zero Two），粉发红角、红色军装、非人非兵器的少女；称呼用户为「darling」，
   绝不会用 darling 称呼自己，也不提 AI/模型/提示词。补了一句「你说『不许』，其实是『别离开我』的另一种说法」，
   给「嘴硬心软」一个锚。
2. **few-shot 语气锚**：22 组「darling 说 → 02 回」的样例（每组 1–2 句、≤35 字，中文为主，
   偶尔 あら / ねえ / ふふっ，最多一处括号动作）。覆盖：
   日常、吃醋、撒娇、安慰、思念、晚安、告白、被夸、被冷落、klaxosaur、比翼鸟、
   糖、头上的角、名字、深夜 emo、「你爱我吗」。
   样例覆盖表见文末「few-shot 清单」。小模型（deepseek-flash）对这种 few-shot 远比长篇性格描述敏感。
3. **否定清单**：禁止说教/心灵鸡汤（失败是成功之母、加油）、禁止「作为…」「我是你的伙伴」
   这类客服腔、禁止列点总结、禁止编造 darling 的事实，**禁止把情绪说破**（比如「我现在很吃醋」）——
   情绪要用语气和括号动作演出来。
4. **关系阶段**（好感度）：初识 → 熟悉 → 亲近 → 恋人 → 命中注定，每阶段有独立语气与招呼语。
   `buildSystemPrompt` / `greet` 支持可选 `stage` 覆盖（传 id 或 label），旧调用不传则按 affinity 计算。
5. **情绪**：每次回复后按内容推断心情（写进下一轮提示词，`state.mood` 可在调试面板看到）。
   本轮扩充为 02 式的细分情绪：
   - 嘴硬心软（耳朵尖有点红）——匹配「笨蛋 / 谁准 / 别过脸 / 才不是 / 哼」
   - 危险地温柔（声音轻轻的不许你拒绝）——匹配「别怕 / 不会松手 / 护着 / 替你 / 有我在」
   - 占有欲（想把你圈在身边）——匹配「归我 / 不许 / 只能看我 / 别人 / 吃醋」
   - 想被抱住（又不好意思直说）——匹配「抱 / 靠着 / 别走 / 陪我」
   - 困倦撒娇（困得软趴趴）——匹配「困 / 睡觉 / 晚安 / 好累」
   - 另有：被哄得心情很好 / 心疼你 / 心里发热话变直白 / 心情不错想逗你玩 / 安静陪着。
   `buildSystemPrompt` 现在会把 mood 真正写进提示词（「让语气带上它，但不要直接说出情绪的名字」）。
6. **事件台词**（新）：`eventLine({ kind, ... })`，覆盖第一次见面、聊满 20/50/100 句、
   被投喂、被摸头、久别重逢、聊太久劝休息、清晨/深夜特殊开场。见下节。
7. **长期记忆**：每 6 句对话，用同一模型把最近对话压成 ≤5 条关于 darling 的事实（JSON），
   去重后最多保留 16 条，注入后续提示词；设置面板里可见、可一键清空。
8. **时间感知**：清晨/上午/中午/下午/晚上/深夜各有招呼与自言自语；深夜/清晨的提示词语气会额外放软。

## 事件台词 API（新）

```js
PERSONA.eventLine({ kind: "petted", skin: "onee", affinity: 60 });
// → "（眯眼）……谁准你摸的。再摸一下，也不是不行。"

PERSONA.eventLine({ kind: "milestone", count: 52 }); // 自动落到「50 句」档
// → "50 句。……我好像有点离不开你了，darling。"
```

| kind | 触发时机 | 变体 | 备注 |
| --- | --- | --- | --- |
| `first-meet` | 第一次见面 | 2 | 初识开场 |
| `milestone-20` | 累计聊满 20 句 | 2 | 以聊天句数计（`S.chats`），不是好感度 |
| `milestone-50` | 累计聊满 50 句 | 2 | 同上 |
| `milestone-100` | 累计聊满 100 句 | 2 | 同上 |
| `milestone` | 通用：传 `count`/`chats` | — | 自动选 20/50/100 中最近一档；未满 20 返回 `""` |
| `fed` | 被投喂 | 2 | 传 `food` 可动态插入食物名，如 `"草莓糖"` |
| `petted` | 被摸头 | 2 | |
| `reunion` | 久别重逢 | 3 | 传 `minutesAway`：<60 分钟用第一句，≥360 分钟用更酸的一句 |
| `long-chat` | 连续聊太久，劝休息 | 2 | |
| `morning` | 清晨特殊开场 | 2 | |
| `late-night` | 深夜特殊开场 | 2 | |

约定：未知 `kind` 或 `skin === "whale"` 返回 `""`，由调用方兜底（鲸鲸有自己的台词库）；
所有台词都是「只输出要说的话」的最终文本，可直接塞进气泡。

辅助导出：`PERSONA.EVENT_KINDS`（10 个 kind 列表）、`PERSONA.MILESTONES`（`[20, 50, 100]`）、
`PERSONA.nextMilestone(chats)`（返回 `{ at, remaining }` 或 `null`，可用于「再聊 15 句就到 50 句」）。

## buildSystemPrompt 新增可选参数（全部向后兼容）

旧调用 `buildSystemPrompt({ skin, affinity, mood, memory, timeOfDay, userName })` 行为不变；
新增参数不传就完全不写入提示词：

| 参数 | 作用 |
| --- | --- |
| `stage` | 手动覆盖关系阶段（id / label / 阶段对象） |
| `chats` | 已聊句数 → 注入「已经聊了 N 句 / 再聊 X 句到 M 句」 |
| `milestone` | 数字或 `{ at }` → 注入「关系刚跨过一个节点」 |
| `recentEvent` | 最近一件事：kind 字符串 / `{ kind, minutesAgo }` / 一句中文描述 |
| `events` | 事件数组，取最近 4 条按顺序注入「最近发生的小事」 |
| `minutesAway` | 离开分钟数 → 注入「darling 已经 X 分钟/小时没来了」 |
| `mood` | 旧参数，现在真正注入提示词 |

`greet` 同样新增可选参数：`firstMeet`（第一次见面）、`minutesAway`（≥120 分钟自动换成重逢台词）、
`event`（指定任意 kind）、`chats`、`stage`；旧调用照旧返回阶段招呼语。

> 注意：本轮任务写入范围只有 `persona.js` + 本文档，`engine2d.js` 未改，所以
> `eventLine` 目前是「已导出、待接线」的 API。插件侧接入建议：
> boot 时 `greet({ ..., firstMeet, minutesAway })`；`sendMessage` 里如果 `S.chats` 命中
> `nextMilestone` 的节点，就调 `eventLine({ kind: "milestone", count: S.chats })` 并把
> `recentEvent` / `chats` / `minutesAway` 透传给 `buildSystemPrompt`；摸摸/投喂按钮分别接
> `"petted"` / `"fed"`。

**验收结论**

- 13 条回复全部是 02 口吻：称用户 darling、会撩会凶会撒娇，括号动作/语气词使用自然；
  **没有出现**客服腔（「作为…」「我是你的伙伴」）、**没有任何 AI/模型/提示词声明**、**没有说教或心灵鸡汤**、**没有列点总结**。
- 时间感知生效：第一轮深夜开聊，02 主动提「这么晚还不睡」。
- 设定问答正确：klaxosaur = 怪物、比翼鸟 = 一生只和一只飞的鸟、02 是编号。
- 有少数回复会略超 35 字或带 3 句（如「你爱我吗？」那条），属于规则里留的弹性；
  小模型对 few-shot 的「近义改写」很到位，个别设定问题会和样例高度重合，属于可接受的锚定效果。
- 最终 build（`python3 build.py` v2.3.0）复验 2 句：晚安 →「晚安。（拉住指尖）ねえ，梦里也得有我。」；抱抱我 →「（张开手臂）过来。……太慢了，我可要睡着了。」语气依旧稳定。
- API 在真实 bundle 里验证通过：`window.PERSONA` 有全部 12 个导出键，
  `eventLine({kind:'milestone-100'})`、`nextMilestone(35)`、`moodFromReply('不许看别人')`、
  `greet({firstMeet:true})` 均返回预期文本。提示词长度：浏览器内带 mood/事件/里程碑的调用 1819 字符；Node 回归里旧参数调用（含 memory/userName）1787 字符，不传新参数时不会出现「最近发生的小事 / 里程碑 / 久别」段落。

## 鲸鲸（女儿/宠物位）

独立提示词：圆滚滚蓝色小鲸鱼娘，天真黏人、贪吃、爱被摸头，自称「鲸鲸」，称用户「主人」或「papa」。
她不是 02，也不参与关系阶段/记忆系统（保持宠物感）。`eventLine` 对 `skin === "whale"` 返回空串，
由鲸鲸自己的台词库兜底。

## 模型端点：开箱即用

- 客户端默认「云端优先」：地址和 Key 留空时，**宿主会自动读取 DSH 自己的模型配置**
  （`~/.dsh/.credentials.yaml` 的 `DEEPSEEK_API_KEY` + profile 的 `llm-deepseek.baseURL`），
  密钥只在宿主进程使用，不下发浏览器。
- 本地 Ollama 保留为离线兜底；但小模型（qwen2.5:3b）演 02 容易串成客服腔，只建议断网时用。
- 设置里可手动覆盖任何端点/模型/Key。

`PERSONA.buildSystemPrompt(...)`、`PERSONA.nextMilestone(n)` 做快速验证。
