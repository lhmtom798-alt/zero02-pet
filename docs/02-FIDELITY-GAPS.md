## 三、可选路线（按性价比）

1. **保持现状 + 微调（推荐）**：在现有 TDA 基础上继续做贴图/着色级优化，性价比最高；本项目已经完成 90% 的"观感"工作。
2. **换/做模型**：找建模师按动画设定重做头部（圆脸、成束头发、嘴部几何）→ 效果质变，但需要外部 3D 资产。
3. **驾驶服皮肤**：`models/mmd/ZeroTwo-Plugsuit/` 有一套 02 驾驶服模型（红装甲、紧身），可作为第三套服装；但贴图有噪点、与军装是两个造型，需要单独适配（约 0.5 人日）。
4. **线稿后处理**：加一层屏幕空间描边/纸纹，让画面更像动画截图；对整体观感有加分，但可能导致 UI 文字变糊（需谨慎）。

## 四、当前建议

- 继续用 TDA 军装作为主形象（最还原）；
- 想"更动画"，优先投入 **线稿后处理**（低风险、观感提升明显）或 **驾驶服第三皮肤**；
- 真正的"复刻到无差"需要重新建模，属于外部美术工作，不是参数调整能完成的。

## 五、驾驶服第三皮肤可行性（本轮实测）

`models/mmd/ZeroTwo-Plugsuit/ZeroTwo_ArmorSuit.pmx`（292 骨 / 432 morph / 24 贴图）：

- 骨骼名是**英文游戏命名**（Hips / Spine / Chest / Left arm / Left elbow … + 大量面部骨如 Mouth_L、Eye01_S_L）；
- mmd-parser 复读发现 **160 处 parentIndex >= 自身索引**（预览 payload 的父子乱序），即骨架同样需要重建；
- 视觉：红色驾驶服（连体紧身衣），脸/头发与 TDA 相近但贴图带白色噪点。

**结论：暂缓。** 要接入需要：① 英文→MMD 标准骨名映射表；② 全量父子重建（约 292 骨）；③ 表情 432 个里挑出可用子集；
④ 贴图去噪。预计 1–2 人日，且它是"另一个造型"（驾驶服），不影响当前军装主形象。若之后要做，按此清单执行。

## 六、尝试过但否决的效果（记录，避免重复踩坑）

1. **海报化 + 纸纹 SVG filter**（feComponentTransfer 离散色阶 + feTurbulence grain）：
   实测会让背景的柔光暗角变成明显"椭圆光斑"，人物平涂发灰，观感变差 → 否决，保留"动画滤镜"（轻度提饱和/对比 + 柔光暗角）。
2. **把肩章改白**：对照 2D 立绘确认 02 肩章本就是深色金边 → 不改。

## 七、尝试并否决：屏幕空间线稿后处理（ink outline）

**做法**：正常渲染到 RT → 用 overrideMaterial 再渲法线/深度 → 全屏 shader 做 8 方向 Sobel → 深色线叠回彩色图。

**实测问题**（`shots/r58-ink-cmp.png`、`r58-ink3-crop.png`、`r58-ink4-crop.png`）：
1. 法线/深度在角色内部（脸上、衣服褶皱、腿部）也会产生大量假边 → 脸变脏、衣服出现虚线；
2. 低分辨率边缘 pass 导致线条断续（锯齿），全分辨率又太贵；
3. 与已有的反向外壳描边叠加后层次混乱，整体反而更"糊"；
4. 色彩空间/色调映射需要额外处理（首版整屏发暗红）。

**结论**：**否决，代码已移除**（避免死代码/性能损耗）。现有"反向外壳描边（分层线宽）+ 贴图细节"的效果更干净；
如果以后要做线稿，正确方向是**手绘风格的发片/衣服轮廓贴图**或离线烘焙描边，而不是实时屏幕空间边缘检测。
