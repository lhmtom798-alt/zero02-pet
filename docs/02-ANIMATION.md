# 02 的骨骼动画与待机演出

实现：`src/3d/mmdchar.js`（MMD 骨骼 + morph 表情 + 程序化物理），本轮新增「活人感」细节。
调试：预览页（`?z02debug=1`）里 `__z02.getChar()` 暴露 `candyPose()` / `debug` 辅助方法。

## 已有动作

| 状态 | 内容 |
|---|---|
| idle | 呼吸（肩/胸）、约 18s 一次的重心左右转移、头部缓慢环视、手臂轻摆、随机眨眼 |
| 视线 | 头部用**二阶弹簧**跟随鼠标（带延迟、最大 ±0.40 rad、静止时缓慢环视"偷看"再转开） |
| pat（被摸） | 下蹲蓄力 → 起跳 → 落地回弹；双手抬到脸侧；脸红眯眼 |
| happy / talk / sleep / shy / stretch / wink / eat | 各自的骨骼姿势 + morph 表情 + 口型循环 |
| 物理 | 头发 47 根骨骼弹簧（头部角速度惯性 + 身体位移惯性）、裙摆 150 根骨骼轻微摇曳 |

## 棒棒糖待机演出（02 标志性小动作）

- 道具已建模并挂到 `左手首` 骨骼（糖球 + 糖纸高光 + 糖棒）。
- 待机时每 **20~40 秒**随机演一次：抬手 → 糖送到嘴边 → 舔两下 → 放下（约 3.2 秒）。
- 面板打开 / 非 idle 状态 / 被摸等动作时不触发，避免打架。
- 手动触发：`__z02.getChar().candyPose(3.2)`；调试：`char.debug.forceCandy()`（可指定延迟）。

## 眨眼与表情节奏

- 眨眼间隔随机 2~5 秒，偶尔连眨（double blink）/慢眨，由 morph `まばたき` 驱动。
- 情绪 morph（笑い/ウィンク/照れ/口型）由状态与聊天语气驱动。

## 性能

- 每帧只做骨骼旋转/弹簧积分与少量 morph 权重插值；头发/裙摆共 197 个弹簧积分，开销可忽略。
- 不加新渲染 pass、不加新依赖。
