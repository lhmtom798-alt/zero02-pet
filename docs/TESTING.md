# 测试与验收（zero02-pet）

三套无头浏览器自动化测试，全部通过 `tools/serve.py`（:8899）+ 无头 Chrome（`tools/shot.mjs`）执行。

```bash
node tools/smoke.mjs          # 基础冒烟：14 项
node tools/smoke.mjs --fast   # 基础核心 2 组：9 项，约 30 秒
node tools/soul-smoke.mjs     # 灵魂冒烟：16 项
node tools/render-smoke.mjs   # 渲染冒烟：16 项
```

## 1. 基础冒烟（tools/smoke.mjs，14 项）

- 组 1：3D 加载（骨 > 300）、摸头/投喂加好感、聊天计数、即时记忆提取、无未捕获 JS 错误
- 组 2：小请求发起/完成、晚安仪式、睡眠机制
- 组 3：模型切换（TDA ↔ Darling）、数据导出、TTS 可用性、画面风格状态

## 2. 灵魂冒烟（tools/soul-smoke.mjs，16 项）

- 组 1：话题入库、约定入库、夸奖入库、接话题追问、约定提醒、夸奖回想
- 组 2：心情驱动（黏人 vs 懒懒、犯困阈值）、时段台词、记忆/话题上限、周记去重、记忆写入裁剪
- 组 3：生日解析、生日专属台词、认识天数可读

## 3. 渲染冒烟（tools/render-smoke.mjs，16 项）

- 组 1：TDA 骨骼、发量 1.06、眼睛 1.26、9 姿势无 NaN、表情驱动（笑い/照れ）、拍照导出非空
- 组 1.5：取景切换（半身拉近/视点上移/切回全身）
- 组 2：Q 版取景切换、切回御姐、2D 回退、切换无异常
- 组 3：鲸鲸 VRM 加载、表情/口型、浮动摇摆

## 说明

- 测试通过 `__z02` 调试 API 驱动（`window.__z02`，仅 `?z02debug=1` 时启用）。
- 无头环境没有音频设备，TTS 只验证"可用性/调用计数"，不验证实际发声。
- 表情/姿势注入要在引擎状态机覆盖前退出，测试中通过状态切换 + 延时采样实现。
